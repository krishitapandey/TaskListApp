#  Task Manager App

A clean, responsive, and modern To-Do application built with React and Tailwind CSS. Features drag-and-drop task reordering, filter tabs, dynamic task counting, dark/light theme switching, and automatic persistent storage.

---

## Features

- **Task Management:** Add, complete, and delete tasks easily.
- **Search & Filter:** Filter tasks by status (`All`, `Active`, `Completed`) or search by name with debounced inputs.
- **Drag & Drop:** Reorder tasks seamlessly using native HTML5 drag-and-drop.
- **Task Counter:** Real-time indicator showing remaining incomplete tasks.
- **Dark & Light Mode:** Toggle between light and dark themes with persistent custom styling.
- **Local Persistence:** Saves all task states locally using `localStorage` so data remains available across page reloads.
